# Week 7 : Interactive Furniture Editing & Paint Customization

## Error / Problem

Buyers and real estate agents wanted to experiment with the auto-furnished layout—moving a sofa, adding a study desk, deleting an extra chair, or previewing different wall paint colors.

## Relevant Context

In `v2-final`, the side panel (`#tab-furniture`) needed to communicate seamlessly with the 3D scene graph generated by `ptt_furnish` and `ptt_render`.

## Key Observation

By naming every furnished glTF node deterministically (and passing a `furniture` manifest list alongside the GLB), the frontend can bind Three.js transform controls directly to individual furniture pieces and dynamically swap wall material colors.

## Solution

Coordinated the `furniture` manifest schema between `ptt_furnish` and `app.js`:
- Clicking any furniture mesh in the 3D view selects it and displays its name and room in `#selCard`.
- Users can add new items from the furniture library (`#library`), translate with drag arrows (`G`), rotate (`R`), or remove (`Delete`).
- Added curated wall paint swatches plus a custom HTML5 color picker (`#paintCustom`) so buyers can preview interior palettes live.
